
# AI Disclosure

AI tools were used as a supporting resource during the development of this assignment.

## How AI Was Used

### 1. Debugging and Troubleshooting
AI was used to help understand and debug errors encountered during development, including:
- Docker and container-related errors
- Kubernetes configuration and deployment errors
- CPU allocation and scheduling issues in Minikube
- YAML configuration errors
- API and request-format errors

For example, AI helped identify configuration issues in the Kubernetes Deployment and understand why Pods were not being created as expected.

### 2. Understanding Docker Concepts
AI was used to clarify concepts related to Docker, particularly:
- Multi-stage Docker builds
- Differences between naive and multi-stage images
- Docker image size reduction
- Docker Compose and service networking

The final Dockerfiles and commands were tested and used as part of the implementation.


### 3. Documentation and Explanation
AI was also used to help structure explanations, README sections, and documentation so that the implementation and results could be presented clearly.

## Impact

AI was used primarily for **debugging, understanding concepts, and improving documentation**. The implementation, commands, experiments, testing, and final results were executed and verified by me.
